## Испытания 0.3.0

Команды без production и платных API:

```bash
python -m compileall -q bot.py voicebot scripts tests
python -m pytest -q
python scripts/media_doctor.py
```

Проверки используют искусственные идентификаторы/сообщения, временную SQLite,
секундную тишину и httpx.MockTransport. Реальная локальная подготовка проверена
на FFmpeg 6.1.1; GitHub CI выполняет Python 3.10/3.12 с FFmpeg 8. Ограничение
stack=2 МиБ позволяет FFmpeg 8 создавать вспомогательные потоки внутри AS=512 МиБ,
без увеличения лимита памяти. prlimit ограничивает также CPU, размер файла,
число файлов/процессов, а отмена/таймаут убивают всю дочернюю группу.

Приёмочная матрица:

- Контракт: RUB, точные десятичные значения, hash, владелец/публикатор,
  candidate/published, unit/API, все положительные компоненты, свежесть и replay.
- Клиент: недоступная сеть, 304 без ложного продления срока, испорченный кеш,
  возврат последней достоверной версии, обновление без рестарта, pause-маркер.
- Деньги: дроби и округление один раз, конкуренция и идемпотентность, месяцы
  29–31/високосный февраль/Moscow, сгорание бесплатных и сохранение дополнительных,
  неизвестный исход/перерасход/Generation ID/отзыв прав до отправки.
- Маршруты: нулевая группа молчит и сохраняет auto_enabled; ручной /tr в ней
  списывает личные средства, кеш после перезапуска не вызывает HTTP повторно.
- Медиа: содержимое вместо имени/MIME, плохие/длинные/неизвестные файлы,
  пределы скачивания/декодирования/base64, удаление временных файлов, отдельная
  /trf, подмена/просрочка/повтор кнопки и отзыв права при реальной подготовке.
- UI: личная история не уходит в группу; чужие кнопки/ревизии/периоды,
  двойное подтверждение, отрицательный остаток/удержанные деньги запрещены;
  /cancel, права администратора, очередь запроса средств и справки.
- Миграция: pre-money SQLite → пробная WAL-копия → новая схема; исходная база
  неизменна, права/кеш/старый REAL сохранены, перезапуск не удваивает журнал.
- Совместимость: старый выпуск без договора не проходит prepare/apply для
  денежной БД; будущая схема отвергается до WAL/миграции; копирование будущей БД
  для сохранности допускается. Удаление маркера не обходит наличие money-таблиц.
- Обновление: новый main/изменённый подготовленный код/неверный KillMode/опасные
  пути останавливают переключение до stop; окончательный backup содержит WAL
  и существующий тарифный кеш. После начала новой версии БД не заменяется и
  старый процесс не запускается автоматически при ошибке.

Локально: 181 тест и 67 подслучаев успешно, compileall успешно, media_doctor
подтвердил ogg/mp3/wav/flac. CI на точном head фиксируется в PR части #24. Репозиторные
проверки не доказывают реальные серверные ресурсы, текущие пути и работу Telegram.
