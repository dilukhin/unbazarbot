# Unbazarbot — текущее состояние

Дата актуализации: 2026-10-28. Реализацию подтверждает main GitHub;
новой проверки работающего vserv в этой серии не выполнялось.

## Программа базариков

В main последовательно слиты спецификация PR #25, общий клиент тарифов PR #26,
точный журнал PR #27, резерв/фактический расход/бюджеты PR #28, расширенное
ручное аудио PR #29 и интерфейс PR #30. Задачи #18–23 закрыты.
Последний проверенный main перед приёмочными изменениями #24:
`96918801ab1775fcc6aac42424b64f994ed0c866`.

[Приёмка выпуска](bzr_release_acceptance_ru.md) содержит карту файлов, PR,
коммиты слияния, проверки и оставшиеся зависимости. Новые деньги считаются
целыми долями 10^-9 Б; 1 Б = 0,01 ₽. Пользователь получает 1000 Б, группа по
умолчанию 10000 Б, у каждого свой месяц. Авто тратит групповые средства и
молчит при исчерпании; ручной /tr в группе — личные. /trf требует отдельного
права и проверяет фактическое содержимое. /balance и история приватны;
/help, /helphelp и административные подтверждения доступны в коде.

## Ограничения выпуска

- Единственный поставщик цен — agent-toolchain PR #111/#112, задача #110 закрыта.
  Первый опубликованный снимок 28.10.2026: 579 моделей, ни одной пригодной для
  нового финансового допуска. Неизвестные API/units не заменяются догадками.
- Рабочие STT ожидают подтверждения метаданных RouterAI в
  [agent-toolchain #113](https://github.com/dilukhin/agent-toolchain/issues/113).
  Каталог и его потребитель работоспособны; это отдельный предел новых оплат.
- `money.global_daily_rub` по умолчанию равен строке "0". Производственная
  конфигурация этой серией не менялась. После установки без явного значения
  новые платные запросы остановятся; кеш при действующих правах остаётся доступен.
- Новый платный formatter выключен в обработчике даже при старом enabled=true:
  отдельного доказанного токенного резерва пока нет. Старый оформленный кеш
  сохраняется. [Точное поведение](formatter_ru.md).
- #24 и родительская #17 остаются открыты до отдельного управляемого выпуска
  и эксплуатационной приёмки. Репозиторные испытания и защита совместимости
  входят в выпуск 0.3.0; наличие его в main проверяется по PR и CI.
- Production VPS, systemd, BotFather, рабочие config/env/SQLite, реальные
  разрешения и баланс RouterAI не изменялись; платные запросы не выполнялись.

Исторический отчёт ниже относится к 0.2.0 и не подтверждает установку 0.3.0.

### База, копии и журналы

- Окончательная согласованная копия SQLite получена с учётом WAL. Рабочая база
  прошла проверку `health`: `database=ok`, `private_access=true`, `budget=true`.
- Пробное восстановление именно окончательной копии выполнено на отдельной
  временной базе: код 0, схема и база проверены. Рабочая база не заменялась.
- Каталоги данных и копий имеют права 0700; секреты, настройки, SQLite и копии —
  0600. После перезагрузки права сохранились.
- Зафиксировано хранение минимум трёх последних успешных выпусков и их копий,
  текущей окончательной копии и материалов переноса v5. Массовая чистка не выполнялась.
- Настроено отдельное пространство journald `unbazarbot`: постоянный журнал,
  предел 64 МБ, хранение 14 дней. Оно активно после перезагрузки.
  Новые записи: `journalctl --namespace=unbazarbot -u unbazarbot.service`;
  прежние: `journalctl -u unbazarbot.service`. Чужие журналы не очищались.
