# Unbazarbot — текущее состояние

Дата актуализации: 2026-10-08. Источник реализации — основная ветка GitHub.

## Реализовано в коде

- Telegram: длительный опрос через aiogram; RouterAI выполняет распознавание.
- Только сообщения `voice`; обычные `audio` и `document` не распознаются.
- Ручное `/tr` в ответ, автоматический режим явно разрешённой группы.
- Заявки людей и групп, меню `/access`, поиск, страницы и отзыв с подтверждением.
- Постоянные и одноразовые разрешения групп; личное разрешение не даёт прав администратора.
- Конфигурация вне Git, безопасный `config.example.yaml`, внешние секреты и SQLite.
- Атомарный резерв одноразового права и лимитов до RouterAI, запрет параллельной оплаты одного файла одной моделью, `/stats`.
- Платный вызов с неизвестным исходом не повторяется автоматически; резерв минут не возвращается при ошибке.
- Дополнительное оформление текста: отдельная модель, сохранение исходного результата, проверка сохранения слов, возврат исходного текста при ошибке. Включение явное, по умолчанию выключено. `/tr_raw` возвращает исходный вариант.
- `/about`: назначение, версия и ревизия. `/system`: сведения о сервере и среде только администратору в личном чате.
- Блокировка единственного процесса с одной базой, сохранение накопленных обновлений Telegram при запуске.
- Закреплённые зависимости, проверки Python 3.10/3.12 без внешних вызовов, согласованная копия SQLite и пробная миграция отдельно от рабочей базы.
- Серверная процедура `check → prepare → apply`: отдельные выпуски, проверки перед остановкой, сохранение настроек и базы, атомарное переключение ссылки `current`.

### База, копии и журналы

- Окончательная согласованная копия SQLite получена с учётом WAL. Рабочая база
  прошла проверку `health`: `database=ok`, `private_access=true`, `budget=true`.
- Пробное восстановление именно окончательной копии выполнено на отдельной
  временной базе: код 0, схема и база проверены. Рабочая база не заменялась.
- Каталоги данных и копий имеют права 0700; секреты, настройки, SQLite и копии —
  0600. После перезагрузки права сохранились.
- Зафиксировано хранение минимум трёх последних успешных выпусков и их копий,
  текущей окончательной копии и материалов переноса v5. Массовая чистка не выполнялась.
- Настроено отдельное пространство journald `unbazarbot`: постоянный журнал,
  предел 64 МБ, хранение 14 дней. Оно активно после перезагрузки.
  Новые записи: `journalctl --namespace=unbazarbot -u unbazarbot.service`;
  прежние: `journalctl -u unbazarbot.service`. Чужие журналы не очищались.

### Проверки Telegram и пределы подтверждения

По сообщениям пользователя, приведённым в отчёте:

- `/about` показывает установленную версию и ревизию; `/system` —
  сведения о сервере.
- Повтор голосового сопровождается пометкой «Расшифровка из кеша».
- MP3 и документ при обычной отправке пропускаются без ответа; `/tr` в ответ
  на MP3/PDF сообщает, что требуется голосовое сообщение.
- После перезагрузки `/system` отказала обычному пользователю в личке
  и администратору при вызове в группе.
- Пользователь выполнил `/access` и `/stats`, но результат ответов
  в отчёте не описан. Успешная расшифровка **нового** голосового после
  обновления отдельно не зафиксирована; подтверждение кеша не заменяет
  проверку нового вызова RouterAI.

### История переноса

Перенос и аватар (#12) завершены ранее. В исходном отчёте переноса отмечены
окно без опроса около 90 секунд с возможным пропуском накопленных сообщений
прежним кодом и исправленный эпизод широких прав промежуточных локальных копий.
Ретроспективно исключить чужой доступ к тем копиям нельзя; их содержимое
в GitHub не переносилось. Текущая версия сохраняет накопленные обновления,
но не восстанавливает сообщения, отброшенные старым кодом.
