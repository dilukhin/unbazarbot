# Unbazarbot — текущее состояние

Дата актуализации: 2026-10-06. Источник реализации — основная ветка GitHub.

## Реализовано в коде

- Telegram: длительный опрос через aiogram; RouterAI выполняет распознавание.
- Только сообщения `voice`; обычные `audio` и `document` не распознаются.
- Ручное `/tr` в ответ, автоматический режим явно разрешённой группы.
- Заявки людей и групп, меню `/access`, поиск, страницы и отзыв с подтверждением.
- Постоянные и одноразовые разрешения групп; личное разрешение не даёт прав администратора.
- Конфигурация вне Git, безопасный `config.example.yaml`, внешние секреты и SQLite.
- Атомарный резерв одноразового права и лимитов до RouterAI, запрет параллельной оплаты одного файла одной моделью, `/stats`.
- Платный вызов с неизвестным исходом не повторяется автоматически; резерв минут не возвращается при ошибке.
- Дополнительное оформление текста: отдельная модель, сохранение исходного результата, проверка сохранения слов, возврат исходного текста при ошибке. Включение явное, по умолчанию выключено. `/tr_raw` возвращает исходный вариант.
- `/about`: назначение, версия и ревизия. `/system`: сведения о сервере и среде только администратору в личном чате.
- Блокировка единственного процесса с одной базой, сохранение накопленных обновлений Telegram при запуске.
- Закреплённые зависимости, проверки Python 3.10/3.12 без внешних вызовов, согласованная копия SQLite и пробная миграция отдельно от рабочей базы.
- Серверная процедура `check → prepare → apply`: отдельные выпуски, проверки перед остановкой, сохранение настроек и базы, атомарное переключение ссылки `current`.
