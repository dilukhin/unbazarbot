# Оформление расшифровки

После распознавания можно выполнить один дополнительный запрос к текстовой
модели RouterAI. Он предназначен только для пунктуации, регистра букв,
предложений и абзацев. По умолчанию отключён: установка новой версии сама
по себе не включает дополнительный платный вызов.

Рабочий раздел `formatter` имеет `enabled`, `default_model`, словарь `models`
с `provider_model`, ограничения `max_input_chars`, `max_output_tokens` и
`timeout_seconds`. Выберите доступную вам текстовую модель, затем явно поставьте
`enabled: true` и перезапустите службу. Модель в шаблоне — пример, а не обещание
её цены или доступности для конкретной учётной записи.

Запрос использует [официальный интерфейс RouterAI](https://routerai.ru/docs/guides/overview/quickstart).
Сначала в SQLite сохраняется исходный текст. Затем модель получает текст как
данные с инструкцией не менять слова и их порядок. Ответ принимается, только
если последовательности слов и чисел совпадают с исходными без учёта регистра.
Эта проверка предотвращает добавление, удаление и перестановку слов; она не
доказывает правильность расставленной пунктуации.

При ошибке, слишком длинном тексте или изменении слов бот возвращает исходную
расшифровку. Перед дополнительным платным запросом доступ повторно проверяется.
Оформление относится к уже зарезервированному заданию и удерживает его место
до завершения. На одно новое распознавание приходится не более одного запроса
оформления; минутные лимиты считаются по аудио, а не по токенам текстовой модели.

Исходный и оформленный тексты хранятся отдельно. Кеш оформленного результата
связан с настройками модели и версией инструкции. При выключении или смене
оформления старый кеш возвращает исходный текст без нового платного запроса.
`/tr_raw [модель]` в ответ на голосовое возвращает исходный вариант. Старые
расшифровки не переоформляются автоматически.

Стоимость этапов хранится отдельно; `/stats` суммирует сообщённые значения,
а отсутствие сведений показывает отдельно. Неудачный или прерванный запрос
оформления не повторяется автоматически и не уничтожает успешное распознавание.
