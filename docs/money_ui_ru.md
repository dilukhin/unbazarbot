# Баланс, справка и административные бюджеты (#23)

## Пользователь

`/balance` работает только в личном чате владельца. Показываются доступный,
бесплатный, дополнительный и зарезервированный остатки, индивидуальный период,
следующее начисление и его дата по Москве. Дополнительные средства не сгорают.
Положительная сумма меньше 0,000001 Б не называется нулём. Для групп команда
направляет в личку без выдачи персональных финансовых сведений.

Кнопки баланса привязаны к user_id и личному chat_id. Доступны история,
модели со свежестью/предварительным резервом и запрос пополнения. История
показывает начисления, истечение, резервы, расходы и корректировки; отдельно —
последние модели/запросы с фактическим RUB либо ожидающей сверки границей.
Тексты, аудио и Telegram file IDs в финансовой истории не отображаются.

Один запрос пополнения сохраняется до решения; повтор не создаёт дубликат
и не рассылает повторные уведомления. При недоставленном уведомлении запрос
остаётся в административной очереди. Подтверждённое начисление на текущий
период или в несгораемый остаток завершает запрос. Администратор может отдельно
закрыть его без начисления. Приёма платежей/Stars и выдачи доступа этим нет.

`/help` — краткие команды и правило оплаты: авто за группу, ручные вызовы за
человека. `/helphelp` — разделы о базариках, датах, бюджетах, стоимости, файлах,
кеше, сверке, пополнении и приватности. Общая справка не читает чужие балансы.
`/status` в личке кратко показывает свой остаток; в группе — только её бюджет,
дату и известную причину приостановки авто. `/model` и выбор моделей сохраняют
проверку каталога; отсутствие безопасного тарифа не разрешает оплату.

## Администратор

`/access → Бюджеты` и кнопка бюджетов в карточке человека/группы доступны
действующему администратору только в личке. Есть страницы людей/групп, история,
очередь запросов, текущий баланс и следующие отдельные действия:

| Действие | Результат |
|---|---|
| Месячная квота | Новое бесплатное начисление со следующего периода |
| Начисление на текущий период | Бесплатные средства до его окончания |
| Несгораемое начисление | Дополнительные средства без срока истечения |
| Корректировка вниз | Уменьшение только доступного выбранного остатка |
| Право /trf | Отдельное личное разрешение, включая администраторов |
| Закрыть запрос | Завершить запрос пополнения без начисления |

Изменение квоты не переименовывается в пополнение и не переписывает текущий
бесплатный остаток. Корректировка не затрагивает удержанный резерв и не создаёт
отрицательный баланс. Выдача /trf не создаёт личный месячный якорь за человека;
счёт открывается при его явном обращении. Групповой месячный счёт появляется
только после постоянного разрешения группы. Для ещё не открытого счёта
денежные операции недоступны; отдельное право /trf можно выдать явно.

После ввода суммы бот показывает адресата, действие и точную применяемую
сумму; финальная кнопка подтверждает конкретный результат. money_intents
связывает её с администратором, личным чатом, сообщением, адресатом, действием,
сроком 5 минут, версией бюджета и периодом либо revision права /trf.
На подтверждении роль проверяется снова. Старый период, чужой/повторный ответ,
отзыв роли, изменение квоты или поколения права не применяют старое решение.

Решение и использованный токен фиксируются в одной SQLite-транзакции с журналом
и аудитом. Повтор не начисляет второй раз. Кнопка «Отмена» и `/cancel` делают
ожидающие подтверждения недействительными. Пользователь получает уведомление
о применённом изменении; ошибка доставки не отменяет уже записанную операцию.
При возобновлении интерфейса актуальный баланс берётся из SQLite.

В журнале сохраняются ID операции/актора, точные целые доли и тип изменения;
денежные callback данные не содержат суммы или доверенного права на списание.
Округление в атомарные доли едино с финансовым слоем; float не используется.

## Наблюдение и границы

`/stats` остаётся только административной командой в личке: точные RUB отдельно
от исторической REAL-оценки, число неизвестных/несогласованных исходов,
перерасходы, приостановленные модели и общий денежный предел. Расшифровки и
сырой ответ провайдера в неё не входят. Платный formatter не включается меню.

Исправлено определение первого обращения: групповые команды другому боту и
нераспознанные общие slash-команды не открывают личный расчётный период.
Явное обращение к настроенному @username, известная команда, личное сообщение
или callback остаются допустимыми якорями независимо от последующего доступа.

Проверки используют искусственные Telegram/SQLite данные и настоящий Dispatcher
для ввода суммы/подтверждения. Покрываются приватность, другой user/chat/message,
срок, повтор, отмена, новый период, конкурирующее изменение, отзы́в администратора,
границы коррекции, отдельно /trf и отсутствие расшифровки в истории.

Код интерфейса не устанавливает новую версию бота и не меняет BotFather,
рабочую конфигурацию или реальные средства RouterAI. Следующий #24 должен
проверить общую миграцию/восстановление и подготовить конкретный выпуск.
До production остаётся тарифная зависимость agent-toolchain #113; общий денежный
предел по умолчанию 0, новых рабочих прав в этой серии не выдавалось.
