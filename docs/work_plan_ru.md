## Завершить проверку Telegram по #5

Основание: `UB-20261006-02_vserv_update_report_ru.md`.
Обновление и серверные проверки завершены; повторять их не нужно.

1. Уточнить ответ `/access` в личке администратора: открывается меню
   управления доступом, без ошибки.
2. Уточнить ответ `/stats`: показана сводка попыток, минут и лимитов,
   без ошибки. Числовые значения и личные идентификаторы публиковать не требуется.
3. Подтвердить, что после обновления удалось распознать новое короткое голосовое,
   а не только получить старую расшифровку из кеша. Если результат уже есть,
   достаточно подтверждения; иначе выполнить одну такую проверку.
4. Зафиксировать ответы и закрыть #5 после подтверждения этих пунктов.

По отчёту уже подтверждены `/about`, `/system`, кеш, тихий пропуск
аудио/документов, отказ `/tr` для MP3/PDF и отказ `/system` обычному
пользователю и в группе. Новое серверное задание не требуется.

Новые версии не устанавливаются автоматически. Скрипт запускает оператор на
сервере либо локальный агент через `ssh_relay` с рабочего/домашнего компьютера.
Выбор модели и включение оформления остаются отдельным решением.
